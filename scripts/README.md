Usage manage cli examples:

 ```bash
   # Create invitation link
   python -m scripts.manage_cli invite -e user@example.com -u "https://trixie.wedgecountry.de:6565/"

   # Create reset link (user must be registered)
   python -m scripts.manage_cli reset -e user@example.com -u "https://trixie.wedgecountry.de:6565/"
 ```
